## About

This repository contains work completed as part of the **J.P. Morgan Chase Advanced Software Engineering** virtual experience program on [Forage](https://www.theforage.com).

The program simulates working as a software engineer at one of the world's largest financial institutions, with tasks focused on enterprise-grade Java development, financial data systems, and professional software engineering practices.

---

## Program Overview

**Institution:** J.P. Morgan Chase & Co.  
**Track:** Advanced Software Engineering  
**Platform:** Forage  
**Language:** Java

---

## What I Learned

- Enterprise Java patterns used in large-scale financial systems
- How professional engineering teams structure and review code at global institutions
- Financial data processing concepts and system design at scale
- Best practices for clean, maintainable Java code in a collaborative environment
